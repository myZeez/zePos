# Checklist Uji Coba

Tanggal: ____________________

Penguji: ____________________

Perangkat: ____________________

## Aplikasi dan data

- [ ] Aplikasi dapat dibuka tanpa koneksi internet.
- [ ] Database demo dapat direstore.
- [ ] Dashboard menampilkan data demo.
- [ ] Aplikasi dapat ditutup dan dibuka kembali tanpa kehilangan data.

## Produk dan barang masuk

- [ ] Produk dapat dicari berdasarkan nama.
- [ ] Produk dapat dicari berdasarkan SKU.
- [ ] Produk baru otomatis memakai satuan terkecil pcs.
- [ ] Tombol Tambah Pack dan Tambah Dus mudah dipahami.
- [ ] Isi serta harga Pack/Dus terhitung otomatis dan tetap dapat diedit.
- [ ] Barcode satuan yang berbeda memilih satuan yang benar.
- [ ] Barang masuk menambah stok sesuai konversi.
- [ ] Harga jual baru tersimpan.
- [ ] Riwayat stok mencatat penerimaan.

## Penjualan

- [ ] Scan barcode menambahkan produk.
- [ ] Tombol tambah/kurang jumlah bekerja.
- [ ] Sistem menolak jumlah melebihi stok.
- [ ] Pembayaran Tunai dan kembalian benar.
- [ ] Pembayaran Transfer berhasil.
- [ ] Pembayaran QRIS berhasil.
- [ ] Stok berkurang setelah transaksi.
- [ ] Transaksi gagal tidak mengubah stok.

## Cetak

- [ ] Printer nota terdeteksi.
- [ ] Nota 58 mm atau 80 mm terbaca dan tidak terpotong.
- [ ] Nama toko, item, total, bayar, dan kembalian benar.
- [ ] Printer label terdeteksi.
- [ ] Ukuran label sesuai media.
- [ ] Barcode label dapat dipindai kembali.
- [ ] Laporan dapat dicetak.

## Laporan dan keamanan data

- [ ] Pendapatan sesuai total transaksi.
- [ ] HPP dan laba tampil.
- [ ] Filter periode bekerja.
- [ ] Backup berhasil dibuat.
- [ ] Restore backup berhasil.
- [ ] Database sebelum restore mempunyai salinan `.before_restore`.
